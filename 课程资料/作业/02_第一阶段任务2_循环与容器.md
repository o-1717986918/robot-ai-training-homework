# 第一阶段任务2：循环、字符串与容器

## 一、需要配置的环境和工具

沿用第一阶段任务1的 Windows、Python 3.13、pip、编辑器及 Git。在 CMD 运行 `python --version` 和 `git --version`；使用编辑器打开已克隆的个人 Fork。需要重选解释器时，在 VS Code 的命令面板运行 **Python: Select Interpreter**，或在 PyCharm 的 **Settings → Project → Python Interpreter** 中选择 Python 3.13。

## 二、最终任务与提交内容

### 需要学习的内容

- 学习 `while`、`for`、`range`、`break` 和 `continue`，理解循环条件、计数和程序状态。
- 学习字符串遍历、索引、切片、大小写与成员判断，处理字符过滤、格式检查与长度边界。
- 学习列表、字典、集合及排序，理解按数据特点选择容器；练习字典查找和不存在键的处理。
- 自行设计正常输入和边界输入，运行程序并根据输出修正。

**学习资源：**[黑马程序员 Python](https://www.bilibili.com/video/BV1qW4y1a7fU/) 的循环、字符串、列表、字典和集合章节；可选 [CS50P 第2讲](https://cs50.harvard.edu/python/2/)。

**中英字幕视频：**[哈佛大学 CS50 Python 编程全集（附课程课件）](https://www.bilibili.com/video/BV1fFyJBFE92/?p=2)。打开视频后，在选集中选择“循环和容器”相关内容。

**题目编号：**必做 [P05](../题库/01_Python基础与CS50P题.md#p05)、[P06](../题库/01_Python基础与CS50P题.md#p06)、[P07](../题库/01_Python基础与CS50P题.md#p07)、[P08](../题库/01_Python基础与CS50P题.md#p08)。点击编号查看集中题面、接口和验收要求。

完成 Coke Machine、twttr、Vanity Plates、Nutrition Facts 四题，分别放入题面规定的 `coke/`、`twttr/`、`plates/`、`nutrition/` 目录。按要求处理投币循环、元音、车牌边界和未知水果。

提交四题源代码及 `phase1/task02/REPORT.md`，记录运行方式、边界自查和自动评测结果。

### 提交内容与检查

- 在个人 Fork 的本任务分支提交 `phase1/task02/coke/coke.py`、`twttr/twttr.py`、`plates/plates.py`、`nutrition/nutrition.py`；后三个路径同样位于 `phase1/task02/` 下。
- 提交 `phase1/task02/REPORT.md`，记录运行命令、边界输入与结果。个人 Fork 的 Actions 评测完成后补充评测结果，再次推送报告。
- 在个人 Fork 的 Actions 查看四题自动检查结果。

```bat

```

如果当前有需要保留的未提交修改，先完成提交。若本任务分支已在本机创建，将最后一条命令替换为 `git switch student/GITHUB_USERNAME/phase1-task02`。

2. 完成本项内容，在仓库根目录执行，确认 `git status` 后推送：

```bat

```

3. 打开**培训方仓库**的 **Pull requests → New pull request → compare across forks**：选择 `base repository: o-1717986918/robot-ai-training-homework`、`base: main`、`head repository: GITHUB_USERNAME/robot-ai-training-homework`、`compare: student/GITHUB_USERNAME/phase1-task02`，填写任务名称、运行方法与结果，点击 **Create pull request**。在个人 Fork 的 **Actions → Phase1 automatic feedback** 找到本次分支的 push 运行，查看逐题结果与 Artifacts，把运行链接贴入培训方 PR。分支继承此前成果时，PR 检查可能同时包含先前任务。检查失败时修改文件后再次 `git add`、`git commit`、`git push`，PR 更新且 Fork 重新评测。培训方 PR 的 Actions 受 GitHub 外部贡献者审批策略影响，可能显示等待批准；个人 Fork 的 push 评测可供自查。

4. 保留 PR 和已推送分支，下一任务从本分支继续。将大量数据、模型或视频放在培训方可访问的存储位置，在 README 提供链接与 SHA-256；少量结果放任务目录的 `samples/`。不要提交密钥、虚拟环境和完整数据集。
