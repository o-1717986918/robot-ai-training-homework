### 图片目录清单

**类型：课程原创工程题。** 提交文件：`phase1/task04/catalog.py`。

#### 题目描述

扫描一个目录及其子目录，读取每张图片的基本信息，将可用图片写入CSV，将读取失败的图片写入另一份CSV。只读取文件属性和图像尺寸，不做目标识别。

#### 命令行与参数

从课程根目录执行：

~~~text
python phase1/task04/catalog.py INPUT_DIR OUTPUT_CSV
~~~

INPUT_DIR为输入根目录；OUTPUT_CSV为结果CSV文件。错误表与结果表同目录，文件名为结果文件名主体加_errors.csv，例如metadata.csv对应metadata_errors.csv。

#### 输入格式

输入根目录可以包含图片、子目录、其他文件和故意损坏的jpg。有效图解码后可取得宽、高及通道数。灰度图通道数记1；彩色图通常3；带alpha图通常4。

#### 输出格式

结果CSV列至少为`relative_path,width,height,channels,bytes`；relative_path相对于INPUT_DIR，使用/作为分隔符；bytes为原文件字节数。错误CSV列至少为`relative_path,error`。stdout输出`{"success":S,"failed":F}`，分别表示成功读取与读取失败的候选图片数量。

#### 数据范围与边界

空目录为合法输入，两张CSV仍保留表头，计数均0。坏图不能使后续图漏处理。隐藏文件不因隐藏属性自动变成错误；只按扩展名候选与实际解码判断。原题为自编题，基础验收使用可放入内存的小型图片，不要求处理任意尺寸超大图。


#### 样例文件树

~~~text
input/
  a.png       # 400×240，3通道
  sub/b.PNG   # 40×32，3通道
  broken.jpg  # 无法解码
  note.txt    # 非图片，忽略
~~~

运行`python phase1/task04/catalog.py input artifacts/metadata.csv`。

#### 样例stdout

~~~json
{"success": 2, "failed": 1}
~~~

#### 结果CSV示意

~~~csv
relative_path,width,height,channels,bytes
a.png,400,240,3,实际字节数
sub/b.PNG,40,32,3,实际字节数
~~~

字节数必须读取真实文件，不照抄“实际字节数”文字；CSV行顺序不评分。broken.jpg在错误表中出现一行。


#### 验收检查点

覆盖子目录、大写扩展名、中文路径、空目录和坏图；检查尺寸没有宽高颠倒，检查原文件哈希未改变。

**来源与改动：** 课程原创题，无对应CS50P官方原题。

### 批量缩放与另存

**类型：课程原创工程题。** 提交文件：`phase1/task04/resize_images.py`。

#### 题目描述

将目录内每张有效图片等比例缩小到指定最大边长内，在新的目录保存结果；较小图片保持原尺寸，不放大。保留输入的子目录结构，重复运行不能覆盖已存在的输出。

#### 命令行与参数

从课程根目录执行：

~~~text
python phase1/task04/resize_images.py INPUT_DIR OUTPUT_DIR --max-edge M
~~~

M为正整数，默认160；INPUT_DIR和OUTPUT_DIR必须互不包含，不能相同，也不能一个是另一个的祖先目录。输出目录不存在时可以创建。

#### 输入格式

按统一规则扫描输入图片。为正确处理透明图片，读取时应保留已有alpha通道；不要求在本题改变图片颜色空间。

#### 输出格式

输出路径为`OUTPUT_DIR/原相对路径`，文件名和扩展名保留。stdout输出`{"success":S,"skipped":K,"failed":F}`：成功生成、因目标已存在而跳过、读取/处理/保存失败的图片数量。

#### 数据范围与边界

最长边不超过M；缩小后的宽高至少1像素，使用同一比例，取整允许1像素差异。已存在的目标先跳过，不重新覆盖。原图不能修改。若输入输出目录重叠，整体报错退出2，不边遍历边生成。


#### 样例

输入有400×240的a.png、40×32的small.PNG、一个坏图broken.jpg，输出目录最初不存在，M=160。

首次运行stdout：

~~~json
{"success": 2, "skipped": 0, "failed": 1}
~~~

输出a.png为160×96，small.PNG仍为40×32。再次对同一输出目录运行：

~~~json
{"success": 0, "skipped": 2, "failed": 1}
~~~

坏图没有变成合法输出，仍计失败；已生成的两张结果不能被重写。


#### 验收检查点

检查横图、竖图、小图、1像素边、alpha通道、重复运行和目录重叠；不能仅把输出宽高都固定为M。

**来源与改动：** 课程原创题，无对应CS50P官方原题。

### 按CSV组织图片

**类型：课程原创工程题。** 提交文件：`phase1/task04/organize_images.py`。

#### 题目描述

依据外部清单将图片复制到train、val、test三个目录，并形成干净清单与错误表。分组由CSV给定，不做视觉分类推断；一条坏记录不能终止整批。

#### 命令行与参数

从课程根目录执行：

~~~text
python phase1/task04/organize_images.py INPUT_ROOT MANIFEST_CSV OUTPUT_DIR
~~~

MANIFEST_CSV为UTF-8或UTF-8 BOM编码CSV。OUTPUT_DIR与INPUT_ROOT必须互不包含。输出目录不存在时创建。

#### 输入格式

CSV必须有`image_id,relative_path,group`三列，可带额外列。group只允许train、val、test。image_id为非空、仅含字母/数字/下划线/短横的安全名称；重复ID不区分大小写。relative_path基于INPUT_ROOT，不得越出根目录，且指向可解码jpg/jpeg/png。

#### 输出格式

有效图片复制到`OUTPUT_DIR/group/image_id.小写扩展名`，不删除或移动输入。clean.csv列至少为`image_id,relative_path,group`，路径改为输出根目录下的新相对路径；errors.csv记录原行号、image_id与error。stdout为`{"success":S,"failed":F}`，分别计有效复制与失败的CSV记录，不按目录图片数计。

#### 数据范围与边界

从上到下处理；格式合法的ID首次出现后登记，后续同ID均视为重复，即使首条之后因缺图失败。非法分组、坏图、缺图、路径越界、已有目标都计失败。CSV整体缺必要列时退出2。不能以覆盖旧文件消除重跑冲突。


#### 样例CSV

~~~csv
image_id,relative_path,group
p01,a.png,train
p02,b.png,val
p03,missing.png,test
p01,b.png,test
~~~

假设a.png、b.png可读，missing.png不存在，输出目录最初为空，则stdout：

~~~json
{"success": 2, "failed": 2}
~~~

clean.csv包括train/p01.png和val/p02.png；错误表分别记录第4行缺图和第5行重复ID。重复运行时已存在的两个目标也必须记为失败，不能无声覆盖。


#### 验收检查点

检验中文路径、大小写重复ID、缺列、未知分组、相对路径越界和重复运行；clean.csv每条都能对应真实输出文件。

**来源与改动：** 课程原创题，无对应CS50P官方原题。
