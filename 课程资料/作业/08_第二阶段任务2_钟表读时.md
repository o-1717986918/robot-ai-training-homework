# 第二阶段任务2：OpenCV 钟表定位与读时

## 一、需要配置的环境和工具

Ubuntu 24.04、任务1创建的 `robot-ai-vision` Conda 环境、Python 3.11、NumPy、OpenCV 和 Git。在 Ubuntu 终端运行：

```bash
conda activate robot-ai-vision
python -m pip install numpy opencv-python
python -c "import sys, cv2, numpy; print(sys.executable, cv2.__version__)"
```

图片来自仓库的 `assets/clocks/` 和 `assets/clock-scenes/`；独立验收图片及阈值由培训方发放。可选 YOLO 定位时，先按第二阶段任务4配置 PyTorch 和 Ultralytics。[OpenCV 图片入门](https://docs.opencv.org/4.x/d3/df2/tutorial_py_basic_ops.html)。

## 二、最终任务与提交内容

### 需要学习的内容

- 学习图片数组、宽高、BGR/灰度和图像坐标；理解整图坐标、裁剪区域 ROI 与坐标换算。
- 学习阈值、形态学、轮廓、掩膜、Hough 圆与线段，观察各步骤的中间图片；筛选表盘和指针候选。
- 学习由指针角度换算 12 小时制时间，考虑分钟进位和时针偏转；处理多钟、空场景与坏图。
- 可选了解 YOLO 检测框，将定位出的表盘区域交给 OpenCV 继续读时。

**学习资源：**[贾志刚 Python/OpenCV 课程](https://www.bilibili.com/video/BV1cm4y1Q7ec/) 的图像坐标、阈值、形态学、轮廓及 Hough 圆／线；[OpenCV 图片基础](https://docs.opencv.org/4.x/d3/df2/tutorial_py_basic_ops.html)。

第二阶段可以使用 Agent 辅助；提交前自行运行、检查并解释代码。

### 必做：图片中的模拟钟表定位与读时

**提交文件：** `phase2/task02/read_clock.py`。

#### 输入

命令行参数为 `--input 图片目录 --output 结果目录`，递归读取 jpg、jpeg、png。输入包含单钟、多钟、空场景和损坏图片。基础图片为近似正视、12 点朝上、直径至少 120 像素、时分针可区分的模拟钟表；使用配套 12 张基础表盘、三个合成场景以及培训方发放的独立图片。可选择 YOLO 产生候选区域，再由 OpenCV 完成读时；也可使用传统方法定位。

#### 输出与约束

1. 输出标注图，显示表盘框、圆心、时分针和识别时间；输出 `results.csv`，候选钟表每个一行，至少包含 `image,clock_id,bbox_x1,bbox_y1,bbox_x2,bbox_y2,hour,minute,status,reason`。
2. 空场景记录 `no_clock`，无法读时记录 `unreadable` 与原因，坏图记录 `bad_image` 并继续处理；保存关联输入的灰度、阈值、轮廓与候选指针调试图。
3. 图片左上角为原点，x 向右、y 向下；框坐标使用全图坐标，ROI 局部坐标还原到全图。时间采用 12 小时制，12 点记为 12；计算时考虑时针随分钟的偏转及分钟进位。

#### 交付与验收

提交程序、依赖、参数、README、结果 CSV 摘要、代表性标注图、调试图与失败样例。列出 12 张基础图片的成功数、失败数与时间误差；组合场景检查定位数量、重框和空场景。时间误差按 12 小时循环计算：`min(abs(pred-truth), 720-abs(pred-truth))`，单位分钟。独立图片的定位 IoU 和读时误差阈值由培训方发放；标签只用于评估。

### 提交内容与检查

- 在个人 Fork 的本任务分支提交 `phase2/task02/read_clock.py`、依赖、参数与 README，并在 `phase2/task02/samples/` 提供少量结果 CSV、标注图、调试图和失败样例。
- README 记录处理 12 张基础表盘和三个合成场景的命令、成功数、失败数与时间误差。独立图片与阈值以培训方发放内容为准，在培训方仓库 PR 中填写实际运行结果。
