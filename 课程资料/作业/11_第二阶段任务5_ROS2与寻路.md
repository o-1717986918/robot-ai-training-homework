# 第二阶段任务5：ROS 2 通信与网格寻路

## 一、需要配置的环境和工具

Ubuntu 24.04、ROS 2 Jazzy、系统 Python、rclpy、std_msgs、ament_python、colcon 和 rosbag。按照 [ROS 2 Jazzy Ubuntu 官方安装教程](https://docs.ros.org/en/jazzy/Installation/Ubuntu-Install-Debs.html) 配置软件源并安装 `ros-jazzy-desktop`；在 Ubuntu 终端运行：

```bash
sudo apt update
sudo apt install -y python3-colcon-common-extensions ros-jazzy-rosbag2
conda deactivate
source /opt/ros/jazzy/setup.bash
ros2 --help
/usr/bin/python3 -c "import rclpy; print('rclpy 可用')"
colcon --help
```

若终端仍显示 Conda 环境，继续执行 `conda deactivate` 直至退出。每次新开 ROS 终端需要重新执行 `source /opt/ros/jazzy/setup.bash`；确保工作空间中 ROS 节点使用系统 Python。参考 [ROS 2 教程](https://docs.ros.org/en/jazzy/Tutorials.html)。

### 必做：ROS 2 通信与 A* 网格寻路

**提交位置：** `phase2/task05/ros2_ws/`。

#### 题目描述

在 Ubuntu 24.04 的 ROS 2 Jazzy 中创建 `ament_python` 包 `grid_planner`，实现地图发布 `map_source`、路径计算 `planner` 和路径显示 `path_viewer` 三个节点。ROS 使用系统 Python。另提供不依赖 ROS 的 `plan(grid,start,goal)` 函数和 CLI，复用同一寻路核心。

#### 输入、输出与规则

`/training/grid` 与 `/training/path` 使用 `std_msgs/msg/String` 承载 JSON。输入包含 `request_id,width,height,cells,start,goal`：cells 按自上到下、从左到右展开，0 为可通行、1 为障碍，坐标 `[x,y]` 从左上角 `[0,0]` 开始。输出包含相同 `request_id`、`status,path,steps,expanded,elapsed_ms`；状态为 `ok,no_path,invalid,timeout`，成功路径包括起终点，`steps=len(path)-1`。

只允许上下左右移动，每步代价 1；A* 使用曼哈顿距离，求最少步数。起终点相同时返回一格、0 步；尺寸不符、越界或起终点受阻返回 `invalid`；搜索穷尽返回 `no_path`；资源受限返回 `timeout`。

#### 样例

```json
{"request_id":"tiny-01","width":3,"height":3,"cells":[0,0,0,1,1,0,0,0,0],"start":[0,0],"goal":[2,2]}
```

一种最短路径为 `[[0,0],[1,0],[2,0],[2,1],[2,2]]`，步数为 4；扩展节点数和耗时记录实际值。

#### 交付与验收

提交可构建的包、纯 Python 搜索入口、至少三张小图（含无路与非法输入）、节点／话题图、启动命令、BFS/A* 最短步数对比、rosbag 记录摘要与报告；逐步检查路径合法。完成 Sokoban 探索项目 的学员可选将原 Sokoban 求解器接入 ROS 并回放。
