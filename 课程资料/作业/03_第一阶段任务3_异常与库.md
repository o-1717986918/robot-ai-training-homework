# 第一阶段任务3：异常、模块与第三方库

## 一、需要配置的环境和工具

沿用 Windows、Python 3.13、编辑器与 Git。**Windows CMD** 中安装第三方库，并确认它们与当前解释器对应：

```bat
python -m pip install pyfiglet inflect numpy pandas opencv-python
python -c "import pyfiglet, inflect, numpy, pandas, cv2; print(numpy.__version__, pandas.__version__, cv2.__version__)"
python -m pip freeze > requirements-basics.txt
```

最后一条在仓库根目录运行。命令找不到 pip 时，先运行 `python -m ensurepip --upgrade`；导入失败时检查编辑器解释器与 CMD 的 Python 是否一致。[pip 安装教程](https://pip.pypa.io/en/stable/getting-started/)。

## 二、最终任务与提交内容

### 需要学习的内容

- 阅读 Traceback，学习 `try / except / else / finally`，理解 `ValueError`、`ZeroDivisionError` 与 `EOFError`；练习无效输入和输入结束的处理。
- 学习模块、`import`、标准库与第三方库，以及命令行参数 `sys.argv`；使用 `python -m pip` 安装并验证当前解释器中的依赖。
- 用 NumPy 创建数组并查看形状；用 Pandas 读取 CSV、分组并计算均值；用 OpenCV 读取图片、转灰度并另存，记录运行结果。

**学习资源：**[黑马程序员 Python](https://www.bilibili.com/video/BV1qW4y1a7fU/) 的异常、模块与包；可选 [CS50P 异常](https://cs50.harvard.edu/python/3/)和[库](https://cs50.harvard.edu/python/4/)。

**题目编号：**必做 [P09](../题库/01_Python基础与CS50P题.md#p09)、[P10](../题库/01_Python基础与CS50P题.md#p10)、[P11](../题库/01_Python基础与CS50P题.md#p11)、[P12](../题库/01_Python基础与CS50P题.md#p12)、[P13](../题库/01_Python基础与CS50P题.md#p13)。点击编号查看集中题面、接口和验收要求。

完成 Fuel、Grocery、FIGlet、Adieu、Little Professor 五题，分别放入对应题目规定目录，满足异常、EOF、命令行参数与函数接口要求。

附带完成 NumPy 数组形状、Pandas CSV 分组均值和 OpenCV 图片读写／灰度转换的微型练习，在 `phase1/task03/REPORT.md` 记录运行结果；提交五题源码和仓库根目录的 `requirements-basics.txt`。

## 三、提交至作业仓库

培训方仓库：[https://github.com/o-1717986918/robot-ai-training-homework](https://github.com/o-1717986918/robot-ai-training-homework)。培训方为每位学员开通该仓库的写入权限。本文的 `GITHUB_USERNAME` 是占位符：请在每条命令中替换为自己的 GitHub 用户名，例如 `student/robotlee/phase1-task01`。每位学员使用自己的分支；提交的 PR 保留在培训方仓库，**不合并到培训方 main**。其他有仓库访问权限的学员可能看到分支和 PR。

1. 打开Windows CMD，在仓库目录从自己上一任务已推送的分支创建本任务分支：

```bat
cd /d C:\robot-ai\course
git status
git fetch origin
git switch -c student/GITHUB_USERNAME/phase1-task03 origin/student/GITHUB_USERNAME/phase1-task02
```

如果当前有需要保留的未提交修改，先完成提交。若本任务分支已在本机创建，将最后一条命令替换为 `git switch student/GITHUB_USERNAME/phase1-task03`。

2. 完成本项内容，在仓库根目录执行，确认 `git status` 后推送：

```bat
cd /d C:\robot-ai\course
git add -- phase1/task03 requirements-basics.txt
git status
git commit -m "Complete phase1-task03"
git push -u origin student/GITHUB_USERNAME/phase1-task03
```

3. 打开**培训方仓库**的 **Pull requests → New pull request**：选择 `base: main` 和 `compare: student/GITHUB_USERNAME/phase1-task03`，填写任务名称、运行方法与结果，点击 **Create pull request**。在该 PR 的 **Checks / Actions → Phase1 automatic feedback** 查看本次任务的检查结果与 Artifacts。由于分支继承此前成果，检查列表可能同时包含先前任务。遇到失败，修改文件后重复 `git add`、`git commit`、`git push`，原 PR 自动更新；检查未运行时确认分支、提交路径及仓库 Actions 配置。

4. 保留 PR 和已推送分支，下一任务从本分支继续。将大量数据、模型或视频放在培训方可访问的存储位置，在 README 提供链接与 SHA-256；少量结果放任务目录的 `samples/`。不要提交密钥、虚拟环境和完整数据集。
