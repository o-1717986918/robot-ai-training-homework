# 培训方仓库维护与发放说明

正式公开仓库：[https://github.com/o-1717986918/robot-ai-training-homework](https://github.com/o-1717986918/robot-ai-training-homework)。学员 Fork 到自己的 GitHub 账号，在个人 Fork 的分支完成作业，并向培训方仓库创建跨仓库 PR；无需邀请学员或授予培训方仓库写入权限。公开仓库及其 Fork、分支、PR 和日志均可访问。

## 1. 仓库与自动评测

培训方仓库 `main` 保留作业骨架、`.course/grading/`、`.github/workflows/` 和 `课程资料/`。`main` 已启用分支保护，PR 要求批准数为 0。P01—P13 使用固定版本 CS50P check50，P15、P16 使用适配检查，图片题使用课程检查器；洛谷题使用洛谷 OJ，其余项目由学员运行并记录结果。

首次 Fork 后，学员在个人 Fork 的 **Actions** 页面按提示启用工作流；推送第一阶段任务 1—4 分支后，在自己 Fork 的 **Actions → Phase1 automatic feedback** 查看逐题结果和 Artifacts，将对应运行链接填入培训方 PR。

GitHub 对公开仓库外部贡献者 PR 的上游工作流有审批策略：当前策略为首次贡献者可能需维护者批准，上游 PR 的 Checks 可能等待批准。个人 Fork 的 push 工作流提供无需上游审批的自查路径；结果链接由学员写入 PR。Fork 中的评测脚本可以由该 Fork 的所有者修改，因此此反馈用于学习和自查，不能作为防篡改成绩凭证。[GitHub 外部贡献者工作流设置](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/enabling-features-for-your-repository/managing-github-actions-settings-for-a-repository)。

## 2. 提交约定

每名学员在自己的 Fork 使用 `student/自己的GitHub用户名/任务名称` 分支；通过 **compare across forks** 以培训方仓库 `main` 为 base、自己的 Fork 和任务分支为 head 创建 PR。PR 保持开启，不合并到模板 `main`。后续任务从自己的上一任务分支创建，PR 差异可能包含之前任务。培训方根据 PR 标题、分支和学员提供的评测链接查看提交。

## 3. 发放与复核

向学员发放正式仓库地址，以及 B 站数据清单、独立钟表验收图片与阈值、CS 图片标注和视频等课程材料。使用一个独立测试 GitHub 账号按第一项任务实际 Fork、启用 Actions、推送和创建 PR，可核验不同账号的完整体验。已有的单账号线上测试已验证上游仓库的评测器与错误反馈，跨账号 Fork 提交流程需在实际账号环境中验证。
