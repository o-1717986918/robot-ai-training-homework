# 培训方仓库创建与发放说明

本页供培训方建立统一作业仓库。学员从同一个培训方仓库克隆，在仓库内按 GitHub 用户名区分分支，并向该仓库提交 PR。正式仓库已创建：[https://github.com/o-1717986918/robot-ai-training-homework](https://github.com/o-1717986918/robot-ai-training-homework)；原验证仓库仅供验证使用。以下建库步骤供重新部署或维护时参考。

## 1. 创建仓库并上传模板

1. 在培训方 GitHub 账号或组织下创建仓库。公开或私有按培训安排选择；公开仓库的代码与 PR 对外可见，私有仓库中有访问权限的学员可互相看到分支和 PR。
2. 将发放包中的 `培训方作业仓库模板.zip` 解压到本机空目录。确认目录根部有隐藏的 `.github/`、`.course/`、`phase1/`、`phase2/` 和 `assets/`。
3. 创建空 GitHub 仓库时不自动添加 README、`.gitignore` 或许可证。打开解压目录中的终端，在仓库根目录依次运行；地址替换为新建的培训方仓库 HTTPS 地址：

```bash
git init -b main
git add .
git commit -m "Initialize AI training assignments"
git remote add origin https://github.com/o-1717986918/robot-ai-training-homework.git
git push -u origin main
```

4. 在 GitHub 仓库确认 `.github/workflows/phase1-autograde.yml` 和 `.course/grading/` 已上传。通过 **Settings → Actions → General** 允许所需 Actions；`main` 应保留为课程模板。当前 `main` 已启用分支保护：禁止普通协作者直接推送、强推和删除，PR 所需批准数为 0。具有写入权限的协作者仍可合并 PR；课程要求保留作业 PR，不合并到 `main`。不要在评测仓库放置密钥。

## 2. 发放权限与地址

在本个人账号仓库的 **Settings → Collaborators → Add people** 中邀请学员 GitHub 账号，学员接受邀请后即可创建并推送个人分支、创建 PR。培训方为学员开通仓库写入权限；这项操作用于提交作业。告知学员仓库真实 HTTPS 地址、素材发放位置以及个人分支命名约定。所有获访问权限的学员可能看到彼此作业；有独立保密需求时应另行设计隔离仓库。

统一仓库收集时，每个任务的 PR **保持开启**，不合并到模板 `main`。后续任务从该学员上一任务分支创建；不同人的同名作业文件位于不同分支，不互相覆盖。PR 对 `main` 的差异会包含该学员之前的任务，因此 Actions 可能同时检查之前任务。

## 3. 验证与发放

使用测试账号实际克隆仓库，按第一项任务创建分支、推送并创建 PR；在 PR 的 **Checks** 查看 `Phase1 automatic feedback` 及 Artifacts。修改测试解答后再次推送，确认原 PR 的结果更新。学员需要可用的仓库 Actions 配额与网络；配置及权限以实际账号页面为准。[GitHub Actions 仓库设置](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/enabling-features-for-your-repository/managing-github-actions-settings-for-a-repository)。

P01—P13 使用固定版本 CS50P check50，P15、P16 使用适配检查，图片题使用课程检查器；洛谷题使用洛谷 OJ。其余项目依照文档要求自行运行、记录和提交，当前模板不为这些项目提供自动评分。

按课程发放 B 站数据清单、独立钟表验收图片和阈值、CS 图片与标注、视频和考核阈值。正式仓库地址为 https://github.com/o-1717986918/robot-ai-training-homework；发放前为学员账号配置仓库权限。
