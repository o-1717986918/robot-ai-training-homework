## P14｜透明图片合成

**类型：CS50P Shirt的课程改编。** 提交文件：`phase1/task04/overlay.py`。

### 题目描述

读取背景与带透明度的PNG标志，把标志按目标宽度等比例缩放，再按指定左上角坐标进行alpha混合，保存新的PNG。透明区域应透出原背景，不能变成黑色矩形。

### 命令行与参数

从课程根目录执行：

~~~text
python phase1/task04/overlay.py BACKGROUND LOGO OUTPUT --width W --x X --y Y
~~~

BACKGROUND为可读背景，LOGO为4通道PNG，OUTPUT为PNG路径；W为正整数且必须提供；X、Y为非负整数，默认均10。

### 输入格式

背景为灰度或彩色图片时可统一转换为彩色处理；标志必须保留alpha通道。缩放高度按原始宽高比计算，alpha值0表示完全透明，255完全不透明。

### 输出格式

输出新的合成PNG；不要求在stdout打印成功信息，可打印输出路径。错误写stderr并退出2。背景和标志原文件不改变，叠加区域以外像素不改变。

### 数据范围与边界

缩放后标志必须完整位于背景内；位置为负或超出边界时报错，不自动裁掉越界部分。缩放混合取整允许一个灰度级误差。没有alpha通道的标志不能被当成透明图。


### 样例1

~~~text
python phase1/task04/overlay.py assets/images/landscape.png assets/images/logo.png artifacts/overlay.png --width 40 --x 10 --y 10
~~~

400×240背景叠加原始80×80标志，缩放后为40×40，覆盖区域为x从10到49、y从10到49。

### 像素检查样例

若背景某通道为100，标志对应通道为200，alpha为128，混合后应约为150，而非直接变200或0。

### 非法样例

在400×240背景上放置40×40标志，若X=390，则越界，应非零失败，不能声称成功。


### 验收检查点

验证alpha0/255/中间值、不同尺寸、区域外未改变、无alpha标志和越界。

**来源与改动：** 灵感来自[CS50P Shirt](https://cs50.harvard.edu/python/psets/6/shirt/)。原题使用Pillow、给定shirt.png及服装尺寸裁剪；本课程改为OpenCV/NumPy、任意透明标志、指定位置和PNG输出，采用课程图片检查器评测。

## P15｜用分钟描述年龄（Seasons of Love）

**类型：CS50P原题程序/类要求中文翻译，删除学生测试文件作业。** 提交文件：`phase1/task04/seasons/seasons.py`。

### 题目描述

给定生日，计算从出生日至今天共经过多少分钟。出生时间和今天的当前时间都按各自当天午夜00:00计算；闰年应按公历真实日期处理，不能简单用年龄乘365。

### 实现接口

实现main()及至少一个负责日期/分钟或文本转换的辅助函数。使用datetime.date.today()取得今天，日期相减得到经过的天数；模块被import时不开始交互。可以调用inflect生成英文。

### 输入格式

一行生日，严格为YYYY-MM-DD。月份和日期均两位。日期不存在、格式不符等输入应说明错误并通过sys.exit正常失败，不能产生未处理异常堆栈。

### 输出格式

输出表示分钟数的英文单词，句首大写，末尾有`minutes`，单词间不使用and。今天按真实运行日期，不硬编码为样例的参考日期。

### 数据范围与边界

公历闰日参与日期差；一天24小时、一小时60分钟。原题未给出生日年份的额外数字上界。本课程保留原程序要求，删除原题另交test_seasons.py的要求。


### 带固定参考日的说明样例

仅为说明，假设运行日为2000-01-01，输入：

~~~text
1999-01-01
~~~

应输出：

~~~text
Five hundred twenty-five thousand, six hundred minutes
~~~

**说明：** 两日期相差365天，即525600分钟。实际运行日不同，不能直接要求同一输入总得到此输出。

### 非法输入样例

`January 1, 1999`格式不符；`2021-02-29`日期不存在。均应以非零退出码结束，不打印伪造年龄。


### 运行与提交

Windows CMD、课程根目录、Python3.13：

~~~bat
python phase1\task04\seasons\seasons.py
~~~

样例使用原题演示的参考日期，电脑日期保持实际值。正式评测会控制参考日期；保留函数与main的分工以便检查。

来源：[Harvard CS50P — 用分钟描述年龄](https://cs50.harvard.edu/python/psets/8/seasons/)，原作者Harvard University / David J. Malan。题面已完整列于本页，原站仅作署名和核对。中文翻译按CC BY-NC-SA 4.0使用；不包含解答。

## P16｜饼干罐（Cookie Jar）

**类型：CS50P原题程序/类要求中文翻译，删除学生测试文件作业。** 提交文件：`phase1/task04/jar/jar.py`。

### 题目描述

实现一个具有固定容量的饼干罐类。罐子初始为空，可以存入和取出饼干；超容量存入或超出现有数量取出必须拒绝。字符串形式由当前饼干数量个🍪组成。

### 实现接口

class Jar必须保留：`__init__(self, capacity=12)`、`__str__(self)`、`deposit(self,n)`、`withdraw(self,n)`、只读@property `capacity`和`size`。参数列表不改，可加辅助方法。capacity为负数或非整数时抛ValueError；初始size=0。

### 输入格式

类接口直接接收方法调用，无标准输入要求。评测会import Jar、构造对象并按顺序调用方法。本题不强制写main，也不应在import时索取用户输入。

### 输出格式

通过方法/属性返回值与异常表达结果：__str__返回饼干字符串；capacity/size返回对应整数。deposit超容量或withdraw数量不足时抛ValueError，不破坏原先状态。

### 数据范围与边界

默认容量12，容量0合法；负容量、非整数容量非法。空罐str为空串，n个饼干返回n个emoji，不插空格。存取n按非负整数数量理解。按课程决定删除原题的test_jar.py作业。


### 方法调用样例

| 按顺序执行 | 期望状态或返回 |
|---|---|
| j = Jar(3) | j.capacity为3，j.size为0，str(j)为空字符串 |
| j.deposit(2) | j.size为2，str(j)为🍪🍪 |
| j.withdraw(1) | j.size为1，str(j)为🍪 |
| j.deposit(3) | 抛ValueError，j.size仍1 |
| j.withdraw(2) | 抛ValueError，j.size仍1 |
| Jar(-1) | 抛ValueError |

各操作共用同一个j实例，不能用每次新建对象掩盖状态错误。


### 运行与提交

Windows CMD、课程根目录、Python3.13：

~~~bat
python phase1\task04\jar\jar.py
~~~

本题的“输入输出”是接口调用与结果，不需编造CLI交互协议。自查可在Python交互或自己的演示入口进行；正式检测直接调用类。

来源：[Harvard CS50P — 饼干罐](https://cs50.harvard.edu/python/psets/8/jar/)，原作者Harvard University / David J. Malan。题面已完整列于本页，原站仅作署名和核对。中文翻译按CC BY-NC-SA 4.0使用；不包含解答。

## P17｜学习纪念图片

**类型：CS50P Shirtificate的课程改编。** 提交文件：`phase1/task04/certificate.py`。

### 题目描述

用背景、标题和姓名生成一张学习纪念PNG。使用CertificateImage类管理这些输入与输出路径；更换姓名应实际改变图片，不把某个固定姓名写死在绘制逻辑中。

### 命令行与参数

从课程根目录执行：

~~~text
python phase1/task04/certificate.py BACKGROUND NAME OUTPUT --title TITLE
~~~

BACKGROUND为可读背景；NAME是命令行姓名文本；OUTPUT为PNG输出路径；--title可选，默认AI Group Certificate。姓名或标题包含空格时在终端加引号。

### 输入格式

读取背景图与传入文本，不要求相机或其他素材。基础验收采用英文姓名/代号；中文排版只有在自备允许使用字体时作为深入方向，不列必做。

### 输出格式

保存一张包含标题和姓名、尺寸与背景一致的PNG。允许stdout打印输出路径，不要求输出JSON。不覆盖输入背景；输入不可读/参数不合法要明确失败。

### 数据范围与边界

文字需处于画面内并可辨认，允许自行选择字号、颜色与排版，不按像素完全一致评分。姓名改变时输出应随之改变。保留输入原图，输出路径不能等于输入路径。


### 样例

~~~text
python phase1/task04/certificate.py assets/images/landscape.png Ada artifacts/Ada.png
python phase1/task04/certificate.py assets/images/landscape.png Lin artifacts/Lin.png --title "AI Group Certificate"
~~~

两次均产生400×240的PNG，分别可见Ada和Lin，文件内容应不同；原背景哈希保持不变。


### 验收检查点

检查类是否保存必要配置、两个人名的结果是否不同、背景是否保持、图片能否解码；不能只创建同名空文件。

**来源与改动：** 改编自[CS50P Shirtificate](https://cs50.harvard.edu/python/psets/8/shirtificate/)。原题要求PDF、A4与给定衬衫素材；本课程明确改为PNG、可选背景与CertificateImage类，不要求fpdf2，不运行官方shirtificate检查。
