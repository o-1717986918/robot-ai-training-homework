题库仅为 17 道 CS50P 原题及改编题编号；洛谷题直接使用第一阶段任务5的题目链接，原创图片题及后续项目需求均写在对应作业中。培训方作业仓库：[https://github.com/o-1717986918/robot-ai-training-homework](https://github.com/o-1717986918/robot-ai-training-homework)。学员获得仓库访问权限后，按第一阶段任务1克隆仓库、建立自己的分支并提交 PR。

P01—P13 采用固定版本官方 check50，P15、P16 使用适配后的官方程序／类检查，图片任务使用课程检查器，洛谷题使用洛谷 OJ；其余项目按文档要求自行运行、自查并记录结果。每项 PR 保留在培训方仓库，后续任务从自己的上一任务分支继续。培训方需发放 B 站核验清单、独立钟表图片与阈值、CS 素材／类别表／视频和考核阈值。
