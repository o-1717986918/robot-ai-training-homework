# 机器人协会 AI 组作业与项目仓库

本仓库提供学员作业与学习项目的目录模板、练习素材和自动评测。

```text
phase1/       第一阶段任务、考核和探索项目
phase2/       第二阶段任务、考核和探索项目
assets/       作业和项目所需的练习素材
.course/      自动评测程序
.github/      Actions 工作流和 PR 模板
```

学员将仓库 Fork 到自己的 GitHub 账号，在个人分支完成任务，向本仓库提交 Pull Request；任务说明和题库由培训方单独发放。

第一阶段前四项的 Python 作业可在个人 Fork 中使用 GitHub Actions 检查。首次使用时在 Fork 的 Actions 页面按提示启用工作流，并将评测结果链接写入 PR。洛谷题使用洛谷 OJ。

仓库及 Fork 的内容公开可见。请勿提交密钥、账号凭据、虚拟环境、大型数据集、模型权重和视频。
