# 机器人协会 AI 组培训作业仓库

本仓库收录 AI 组两阶段的作业、题库、学习资源与自动评测配置。

- [查看 12 份任务与考核文档](课程资料/README.md)
- [查看 CS50P 原题与改编题题库](课程资料/题库/00_题目总索引.md)
- [培训方仓库维护与发放说明](课程资料/培训方仓库创建与发放说明.md)

培训方为学员配置仓库写入权限。学员克隆本仓库，按任务文档创建 `student/自己的GitHub用户名/任务名称` 分支，完成作业后向本仓库 `main` 创建 Pull Request。PR 保持开启，后续任务从自己的上一任务分支继续。

第一阶段前四项使用 GitHub Actions 自动检查：CS50P 原题使用固定版本 check50 或适配检查，图片题使用课程检查器；洛谷题在洛谷评测。其他项目依任务要求运行并记录结果。任务材料、输出与提交路径以各任务文档为准。

本仓库为公开仓库，代码、分支、提交和 Pull Request 均可被公开访问。勿提交密钥、账号凭据、虚拟环境、完整数据集、模型权重或大型视频。培训方另行发布的资料和阈值以通知为准。
