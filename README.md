# 机器人协会 AI 组培训作业仓库

本仓库收录 AI 组两阶段的作业、题库、学习资源与自动评测配置。

- [查看 12 份任务与考核文档](课程资料/README.md)
- [查看 CS50P 原题与改编题题库](课程资料/题库/00_题目总索引.md)
- [培训方仓库维护与发放说明](课程资料/培训方仓库创建与发放说明.md)

学员先将本公开仓库 Fork 到自己的 GitHub 账号，克隆自己的 Fork，在 `student/自己的GitHub用户名/任务名称` 分支完成作业，再通过跨仓库 Pull Request 提交到本仓库 `main`。无需培训方邀请。每项 PR 保持开启，后续任务从个人 Fork 的上一任务分支继续。

第一阶段前四项在个人 Fork 推送后运行 GitHub Actions 自动检查；首次使用时按提示在个人 Fork 的 Actions 页面启用工作流。将评测运行链接写入培训方 PR。培训方仓库的 PR 检查可能受 GitHub 首次贡献者工作流审批策略影响。CS50P 原题使用固定版本 check50 或适配检查，图片题使用课程检查器；洛谷题在洛谷评测。其他项目依任务要求运行并记录结果。

本仓库和个人 Fork、分支、提交及 Pull Request 均公开可见。不要提交密钥、账号凭据、虚拟环境、完整数据集、模型权重或大型视频。培训方另行发布的资料和阈值以通知为准。
