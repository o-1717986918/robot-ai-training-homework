# 机器人协会 AI 组作业与项目仓库

本仓库提供学员作业与学习项目的目录模板、练习素材和自动评测。

```text
phase1/       第一阶段任务、考核和探索项目
phase2/       第二阶段任务、考核和探索项目
assets/       作业和项目所需的练习素材
.course/      自动评测程序
.github/      自动评测工作流
```

培训方收集学员 GitHub 用户名并邀请加入仓库。学员在自己的分支上传作业和项目；任务说明和题库由培训方单独发放。

第一阶段前四项 Python 作业上传后使用 GitHub Actions 自动检查。算法题及后续任务上传截图或视频。

仓库内容公开可见。
